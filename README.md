# Karistan

## Offline Prompt Engineering Learning Lab

## معرفی Karistan
کارستان  یک شبیه ساز  آموزشی آفلاین/نیمه‌آفلاین برای آموزش مهارت پرامپت‌نویسی به کارآموزان و مربیان هوش مصنوعی  فنی و حرفه ای  است که  این محصول بر اساس استاندارد شغل و کتاب:

«طراحی و پیاده‌سازی پرامپت‌های مؤثر برای سیستم‌های هوش مصنوعی»

طراحی شده تا در شرایط قطعی اینترنت نیز فرآیند آموزش و ارزشیابی متوقف نشود.


شعارهای محصول:

- آموزش متوقف نمی‌شود
- مهارت برای ادامه مسیر
- یادگیری در هر شرایطی

## هدف محصول

- فراهم‌کردن محیط تمرین پرامپت‌نویسی بدون وابستگی به API خارجی
- ارائه درس‌های کوتاه، عملی و کلاس‌محور
- ساخت پرامپت‌های ساختاریافته برای حوزه‌های مختلف
- تحلیل و بهبود پرامپت به زبان فارسی
- برگزاری آزمون آفلاین و ذخیره نتایج در پایگاه داده محلی

## فناوری‌های استفاده‌شده

- Python
- Streamlit
- SQLite
- JSON
- Pandas (برای نمایش داده‌ها و خروجی CSV)
- Ollama (اختیاری، برای تولید متن با مدل لوکال)


## نحوه اجرا

```bash
streamlit run app.py
```

پس از اجرا، آدرس محلی Streamlit (معمولاً `http://localhost:8501`) باز می‌شود و تمام ماژول‌ها قابل استفاده خواهند بود.

## استفاده اختیاری از مدل لوکال Ollama

1. Install Ollama
2. Run: `ollama pull qwen2.5:3b`
3. Run: `streamlit run app.py`

سپس داخل برنامه، از سایدبار گزینه `استفاده از مدل لوکال Ollama` را فعال کنید.
پس از فعال‌سازی، می‌توانید مدل را از سایدبار انتخاب کنید (مثلاً `qwen2.5:3b` یا `qwen2.5:7b`).
لیست مدل‌ها به‌صورت خودکار از `ollama list` خوانده می‌شود.
مدل پیشنهادی برای MVP به‌صورت پیش‌فرض: `qwen2.5:3b`

## استفاده اختیاری از API (gapgpt / OpenAI-Compatible)

اگر می‌خواهید به‌جای مدل لوکال، از رابط API استفاده کنید:

1. یک کلید API از gapgpt دریافت کنید.
2. در سایدبار گزینه `استفاده از API (gapgpt / OpenAI-Compatible)` را فعال کنید.
3. مقادیر زیر را وارد کنید:
   - `Base URL` (مثال رایج: `https://api.gapgpt.app/v1`)
   - `مدل API` (مثال: `gpt-4o-mini`)
   - `API Key`

## قابلیت‌های MVP

1. رابط فارسی RTL
- چیدمان راست‌به‌چپ
- متن خوانا و مناسب نمایش کلاس
- طراحی ساده، آموزشی و قابل اتکا

2. صفحه خانه
- معرفی Karistan
- پیام مبتنی بر کتاب
- بیان مسئله: آموزش متوقف نمی‌شود
- ناوبری کامل به همه ماژول‌ها
- تشخیص خودکار وجود فایل مرجع کتاب

3. نقشه کتاب مرجع
- نمایش سرفصل‌های استخراج‌شده از کتاب
- نگاشت فصل‌ها به ماژول‌های آموزشی Karistan

4. ماژول درس
- بارگذاری آفلاین درس‌ها از `sample_lessons.json`
- نمایش کامل هر درس در 4 بخش:
  - محتوای کامل درس (پیش‌نیاز، اهداف یادگیری، مفاهیم کلیدی، پوشش کامل سرفصل)
  - مسیر تدریس (سناریوی مرحله‌به‌مرحله مدرس/کارآموز)
  - کارگاه عملی (نمونه پرامپت، تمرین ساختاریافته، چک‌لیست، خطاهای رایج)
  - ارزیابی (چک‌لیست خودارزیابی + مینی‌کوییز پایان درس)
- درس‌ها بر اساس سرفصل‌های کتاب و به‌صورت فصل‌محور تنظیم شده‌اند:
  - فصل 0: مقدمه هوش مصنوعی و مفهوم پرامپت
  - فصل 1: تکنیک‌های پایه (Zero-shot تا Few-shot)
  - فصل 1: System/Role/Contextual Prompting
  - فصل 1: Step-back و Chain of Thought
  - فصل 3: شناخت LLM و طراحی پرامپت‌های مستقیم/چندمرحله‌ای
  - فصل 4: تکنیک‌های پیشرفته (Self-consistency, ToT, ReAct)
  - فصل 5: ارزیابی و بهبود (متریک‌ها و A/B Testing)
  - فصل تولید محتوای متنی
  - فصل تولید تصویر
  - فصل 8: تولید ویدیو و انیمیشن

5. تولیدگر پرامپت
- انتخاب دسته‌بندی:
  - آموزش
  - تولید محتوا
  - کسب‌وکار
  - برنامه‌نویسی
  - تصویرسازی
  - شبکه‌های اجتماعی
- ورود موضوع
- تولید خروجی ساختاریافته شامل:
  - role
  - task
  - context
  - output format
  - constraints
  - final prompt

6. بهبوددهنده پرامپت
- دریافت پرامپت خام
- ارائه نسخه بهبودیافته
- توضیح تغییرات
- چک‌لیست امتیاز 0 تا 5 بر اساس:
  - role
  - goal
  - context
  - output format
  - constraints

7. معلم پرامپت
- تحلیل آموزشی پرامپت واردشده
- نمایش:
  - نقاط قوت
  - نقاط ضعف
  - عناصر جاافتاده
  - نسخه بازنویسی‌شده بهتر
  - توضیح ساده مناسب کارآموز

8. Image Prompt Studio
- تولید پرامپت حرفه‌ای تصویر از ایده کاربر
- شامل فیلدهای:
  - subject
  - style
  - lighting
  - camera angle
  - colors
  - details
  - quality
  - negative prompt
- خروجی:
  - توضیح فارسی
  - English image prompt
  - negative prompt
  - بلاک قابل کپی
- توجه: نسخه MVP تصویر واقعی تولید نمی‌کند.

9. Video Prompt Studio
- تولید پرامپت ویدیویی از ایده کاربر
- خروجی:
  - video concept
  - storyboard صحنه‌به‌صحنه
  - camera movement
  - visual style
  - narration text
  - video generation prompt
- توجه: نسخه MVP ویدیوی واقعی تولید نمی‌کند.

10. آزمون آفلاین
- حداقل 15 سوال چندگزینه‌ای
- ورود نام کارآموز
- پاسخ‌گویی، ارسال و محاسبه نمره
- نمایش پاسخ صحیح و توضیح هر سوال
- ذخیره نتیجه در SQLite

11. نتایج
- نمایش:
  - نام کارآموز
  - نمره
  - تاریخ/ساعت
  - درصد
  - وضعیت: قبول / نیاز به تمرین بیشتر
- خروجی CSV محلی

## نحوه استفاده مدرس

1. اجرای برنامه روی لپ‌تاپ مدرس
2. انتخاب ماژول درس و ارائه مفاهیم پایه
3. استفاده از تولیدگر/بهبوددهنده/معلم پرامپت برای تمرین کلاسی
4. اجرای آزمون آفلاین برای کارآموزان
5. بررسی نتایج در بخش نتایج و گرفتن خروجی CSV

## نحوه استفاده کارآموز

1. مطالعه درس‌های کوتاه
2. تمرین ساخت پرامپت در ماژول تولیدگر
3. اصلاح پرامپت‌های ضعیف با بهبوددهنده
4. گرفتن بازخورد آموزشی از معلم پرامپت
5. شرکت در آزمون و مشاهده توضیح پاسخ‌ها

## پایگاه داده محلی

در اولین اجرا، فایل `karistan_results.db` ساخته می‌شود و جدول زیر ایجاد می‌گردد:

`quiz_results(id, trainee_name, score, total, percentage, created_at)`

## محدودیت‌های نسخه MVP

- هیچ API خارجی استفاده نمی‌شود.
- موتور تولید متن کاملاً قاعده‌محور (Rule-based) است.
- احراز هویت کاربران وجود ندارد.
- مدیریت چندکلاسه/چندمدرس هنوز اضافه نشده است.
- تولید تصویر/ویدیو واقعی انجام نمی‌شود و فقط پرامپت ساخته می‌شود.

## مسیر توسعه نسخه بعدی

1. افزودن مدیریت کلاس، گروه و پروفایل کارآموز
2. افزودن بانک سوالات پیشرفته با سطح‌بندی
3. گزارش‌های تحلیلی پیشرفت کارآموزان
4. پشتیبانی از موتورهای محلی LLM (بدون وابستگی ابری)
5. افزوده‌شدن حالت آزمون زمان‌دار و چاپ کارنامه
